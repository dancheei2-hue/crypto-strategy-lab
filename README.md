# Crypto Strategy Lab — audit patch

Этот патч исправляет две методологические проблемы и один параметр экспозиции:

1. Адаптивная модель теперь получает `position_size_pct` из интерфейса и применяет его до расчёта доходности и торговых издержек.
2. Buy & Hold benchmark учитывает стоимость входа (комиссию и проскальзывание), а не объявляется бесплатным gross benchmark.
3. Ручная проверка OOS сохраняет предысторию для индикаторов: индикаторы рассчитываются на полной истории, а метрики — только на финальном отложенном участке.

## Применение

1. Скачайте/клонируйте `crypto-strategy-lab`.
2. Распакуйте архив в отдельную папку.
3. Из корня репозитория запустите:
   `python apply_patch.py`
   или укажите путь к репозиторию:
   `python apply_patch.py C:\\path\\to\\crypto-strategy-lab`
4. Скрипт создаёт резервные копии `app.py.bak` и `regime_engine.py.bak`.
5. Проверьте `git diff`, запустите приложение и сравните отчёты до/после.

Важно: патч не создаёт прибыльную стратегию сам по себе и не разрешает реальные ордера. Это исправления корректности эксперимента; дальше нужны тесты и независимый paper trading.
