# Готовые файлы Crypto Strategy Lab

Архив содержит полностью готовый `regime_engine.py` и скрипт, который безопасно обновляет вызов модели в `app.py`.

## Как применить через GitHub (без поиска строк вручную)

1. Откройте репозиторий и нажмите **Code → Download ZIP**.
2. Распакуйте репозиторий на компьютере.
3. Замените `regime_engine.py` файлом из этого архива.
4. В корне проекта выполните `python apply_app_patch.py`.
5. Проверьте изменения и загрузите заменённые `regime_engine.py` и `app.py` в GitHub через **Add file → Upload files** или обычным коммитом.
6. Streamlit Cloud пересоберёт приложение после коммита.

## Что исправлено

- Адаптивная модель теперь учитывает `position_size_pct`, заданный в интерфейсе.
- Экспозиция и средняя экспозиция отражаются в метриках.
- Buy & Hold benchmark учитывает размер экспозиции и издержки входа.
- Добавлены проверки входных параметров и хронологии данных.

Это исправляет часть корректности тестирования, но не гарантирует прибыльность. Реальные ордера не подключаются.
