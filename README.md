# Crypto Strategy Lab — упрощённый интерфейс

Это обновление заменяет только `app.py`; остальные файлы проекта оставьте из текущего репозитория.

## Установка
1. Откройте репозиторий `dancheei2-hue/crypto-strategy-lab`.
2. Откройте `app.py` → Edit → замените содержимое содержимым нового `app.py`.
3. Сохраните commit и дождитесь перезапуска Streamlit Cloud.

## Что изменилось
- Настройки рынка собраны в левой панели.
- Основной сценарий — загрузить котировки и проверить одну стратегию.
- Автоматический поиск, адаптивная модель, paper trading и выгрузка вынесены в отдельные вкладки.
- Технические метрики и таблицы скрыты в раскрываемые блоки.
- Реальные ордера не отправляются.

Остальные модули (`backtest.py`, `auto_research.py`, `regime_engine.py`, `paper.py`) не меняются.
